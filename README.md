# Práctica 1 CommII_A1_G9

Bienvenidos al repositorio de la **Práctica 1 de Comunicaciones II** de la Universidad Industrial de Santander.

En esta práctica se estudian conceptos de **Radio Definida por Software (SDR)** mediante el uso de **GNU Radio**, implementando bloques personalizados para el procesamiento digital de señales.

El trabajo incluye la implementación y evaluación de un **bloque acumulador** y un **bloque diferenciador**, utilizando diferentes señales en tiempo discreto y herramientas de visualización para analizar su comportamiento.

También se aborda el **análisis estadístico de señales** como parte de la práctica general, considerando parámetros como la media, RMS, potencia y desviación estándar.

## Herramientas utilizadas

- GNU Radio
- Python
- Embedded Python Block
- Vector Source
- Throttle
- QT GUI Time Sink
